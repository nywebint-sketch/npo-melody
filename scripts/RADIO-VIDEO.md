# Видео 8 ГБ в раздел «Радио»

Файл **8 ГБ нельзя** положить в Supabase Storage сайта: лимит размера, нет перекодирования и адаптивного стриминга. Для скорости «как на YouTube» используйте **Rutube** или **YouTube** — плеер на сайте встроит их через iframe (качество подстраивается автоматически).

## 1. Загрузить видео

### Rutube (удобно для РФ, до 100 ГБ)

1. [rutube.ru](https://rutube.ru) → войти → **Добавить видео** → загрузить файл (~8 ГБ, займёт время).
2. Название на площадке: **лекция про АРМА 17**.
3. Доступ: «По ссылке» или «Для всех» — как нужно.
4. Скопировать ссылку вида `https://rutube.ru/video/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

### YouTube

1. [studio.youtube.com](https://studio.youtube.com) → **Создать** → загрузить файл.
2. Скопировать ссылку `https://www.youtube.com/watch?v=...` или `https://youtu.be/...`.

## 2. Добавить запись на сайт

**Через админку (проще всего)**

1. `admin.html` → **НПО РАДИО** → **+ Добавить эфир**.
2. Название: `лекция про АРМА 17`.
3. Дата — любая (для записи с видео важна ссылка, не дата).
4. **Ссылка на видео** — вставить Rutube/YouTube URL.
5. Сохранить.

**Через скрипт**

```bash
SUPABASE_SERVICE_ROLE_KEY="ваш_service_role" node scripts/publish-radio-recording.mjs \
  --title "лекция про АРМА 17" \
  --url "https://rutube.ru/video/ВАШ_ID"
```

Без service role скрипт выведет SQL для Supabase → SQL Editor.

## 3. Как это видят пользователи

- Раздел **Радио** на главной (нужен вход в профиль).
- Блок **Записи** — все эфиры со ссылкой на видео.
- По клику — модалка с плеером Rutube/YouTube (быстрый старт, перемотка, качество).

## Альтернативы

| Платформа   | Ссылка в админке                          |
|------------|--------------------------------------------|
| VK Видео   | `https://vk.com/video-123_456`             |
| Kinescope  | `https://kinescope.io/embed/...`           |
| HLS CDN    | прямой URL на `.m3u8` (плеер hls.js)       |

Прямой `.mp4` на 8 ГБ без CDN не рекомендуется — долгая буферизация.
